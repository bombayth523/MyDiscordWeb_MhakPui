# MyDiscordWeb_MhakPui

เว็บไซต์ส่วนตัวและหน้ารวมลิงก์/ช่องทางการติดต่อของ **barombombie** (เซิร์ฟเวอร์กลุ่มหมักปุ๋ย)
สร้างขึ้นด้วย HTML, CSS, และ JavaScript แบบพื้นฐาน ไม่ต้องพึ่งเฟรมเวิร์กใดๆ

## 🌟 ฟีเจอร์หลัก

- **Discord Widget**: แสดงสถานะและเชิญชวนเข้าเซิร์ฟเวอร์ Discord "กลุ่มหมักปุ๋ย"
- **แชตบอท (Chatbot)**: หน้า `chatbot/index.html` เชื่อมต่อกับ Dialogflow — บอทตอบตามคำถามที่ตั้งไว้ล่วงหน้า ไม่ใช่ AI และไม่ได้เรียนรู้เอง
- **กฎและข้อตกลง**: หน้า `rules/index.html` สำหรับอ่านระเบียบและนโยบายของเซิร์ฟเวอร์
- **คัดลอกข้อมูลติดต่อ**: กดปุ่มเดียวเพื่อคัดลอก Discord username หรืออีเมลไปยังคลิปบอร์ด พร้อม Toast notification แจ้งเตือน

## 📁 โครงสร้างโปรเจกต์

- `index.html` — หน้าหลักของเว็บไซต์ รวม Discord widget และช่องทางติดต่อ
- `chatbot/index.html` — หน้าสำหรับทดลองคุยกับแชตบอท Bombie
- `rules/index.html` — หน้ากฎและข้อตกลงในการเข้าร่วมเซิร์ฟเวอร์
- `style.css` — ไฟล์ CSS สำหรับจัดการรูปแบบและหน้าตาของทุกหน้า
- `script.js` — JavaScript สำหรับฟังก์ชันคัดลอกข้อความ (Clipboard API) และ Toast notification
- `img/` — โฟลเดอร์เก็บรูปภาพ เช่น โลโก้ Discord และไอคอนอีเมล

## 🚀 การเปิดใช้งาน

1. โคลนหรือดาวน์โหลดโปรเจกต์นี้ลงในเครื่อง
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งหรือรัน server เพิ่มเติม
